# 첫 구현 결과 보고 (2026-11-15)

> **운영 준비 미완료.** 카카오 상담 공식 연동(0단계)이 검증되지 않았으므로 '실제 연동 완료'나 '실제 문의 분석 완료'가 아닙니다.

## 1. 실제 동작 부분 vs 데모 부분

| 영역 | 상태 | 비고 |
|---|---|---|
| 카카오 상담 수신 | **미연동** | 공급사(경로 A/B) 미결정·미계약. 어댑터 자리만 있음(`integrations/channeltalk.ts`는 501 반환) |
| 상담 데이터 | **샘플(가상)** | `demo` 공급사, `is_sample=true`, 화면에 '샘플 데이터 / 카카오 미연동' 표시 |
| 수신 파이프라인 | 동작 (샘플 공급사로 검증) | 서명 검증 → 원본 저장 → 큐 → 정규화. 중복·순서 역전·실패 재처리 |
| 계정·초대·권한 | 동작 | 공개 가입 없음, 서버측 권한 검사, 계정 회수 시 즉시 세션 무효 |
| 상담함·메모·할 일·작성 중 표시 | 동작 | 앱 내 고객 발송은 **비활성**(읽기·분석·초안 전용) |
| 영업 단계·견적/계약 수기 등록·이탈 근거·합치기/분리 | 동작 | 변경 이력·되돌리기 포함 |
| 지표(분석실) | 동작 (DB 쿼리) | 샘플 데이터 기준 수치이므로 실제 의미 없음 |
| AI 직원 3명 | 규칙 기반 응답만 확인 | `ANTHROPIC_API_KEY` 미설정 환경에서 개발. **모델 호출 경로는 실제 API로 검증하지 않음** |
| AI 상담 분석·답장 초안·보고서 해석 | 코드 작성, 미검증 | 키 미설정 시 '분석 대기' 표시 동작은 테스트로 확인 |
| 정기 보고·알림함 | 동작 | 워커 실행 필요. Web Push는 미구현(앱 안 알림함만) |
| PWA | 설치 매니페스트·앱 셸 캐시 | 대상 기기·브라우저별 설치/푸시 확인은 미실시 |
| 과거 기록 가져오기 | 동작 | 앱 정의 JSON만. 공급사 일괄 내보내기 가정 안 함 |

## 2. 필수 검증 시나리오 결과

자동 테스트: `npm test` — 24개 통과 (테스트 DB, `ANTHROPIC_API_KEY` 없음).

| # | 시나리오 | 결과 | 방법 |
|---|---|---|---|
| 1 | 동일 수신 이벤트 3회 → 중복 없음 | **통과** | 같은 이벤트 3회 + 다른 이벤트 ID·같은 메시지 ID 1회 → 메시지 1, 문의 1 |
| 2 | 견적 후 무응답 → 가격 이탈로 확정 안 함 | **통과** | '견적 후 회신 대기' 표시, 후속 확인 할 일만 생성(1회), 이탈 평가 0건, 단계 유지 |
| 3 | 같은 고객 동일 프로젝트 재문의 → 기존 건 연결 | **통과** | 상담 종료 후 새 상담방 → 진행 중 기회에 자동 연결 |
| 4 | 다른 프로젝트 문의 → 별도 기회 분리 | **통과** | 분리 API + 이력 기록. 합치기 시 문의 수에서 제외 확인 |
| 5 | 직원 계정 권한 차단 | **통과** | 재무/분석/구성원/설정 403, 미배정 상담 404, 금액 null, AI 도구도 차단, 회수 후 401 |
| 6 | 실제 카카오 테스트 대화 원본 일치 | **미실시** | 공급사·테스트 채널 없음. docs/INTEGRATION.md 4절 절차 |
| 7 | 앱 발송 시 수신 확인·승인·중복 방지 | **해당 없음(비활성)** | `sendEnabled=false` 확인. 발송 기능 미구현 |
| 8 | AI 장애/한도 → 수신 유지, 분석 대기 | **부분 통과** | 키 없음 상태에서 수신 유지·'분석 대기'·규칙 응답 확인. 실제 API 장애·한도 도달은 미검증(한도 로직은 코드상 구현) |
| 9 | 과거 이력 없음 → 시작일·누락 범위 표시 | **통과** | 홈에 연동 상태·샘플 여부·첫 수신 시점, 분석실에 미분류/유입 미확인/사유 불명 분모 표시 |
| 10 | PC/휴대폰 동기화·사용성 | **부분 통과** | 1440px·390px 화면 캡처로 가로 스크롤 없음·버튼/입력창 노출 확인. 동기화는 서버 상태 공유 + 10~30초 재조회(실시간 푸시 아님). 실기기 확인 미실시 |

추가 확인: 서명 불일치 웹훅 거부·미저장, 미구현 공급사 501, 순서 역전 도착 시 '답변 대기' 판단·상담 상태 보존, 첫 응답 시간에서 자동 안내 제외, 스팸/테스트 별도 집계, 계약 기록 없이 '계약 확정' 불가, '확인' 이탈 사유는 근거 필수, 퍼널 누적 단조 감소, CSRF 헤더 없는 변경 요청 거부, 모델 전송 전 연락처 마스킹, 알림 제목에 원문 미포함, 가져오기 중복 방지.

## 3. 미완료 항목

1. **카카오 공식 연동 0단계 전체** — 현재 채널 상태 확인, 공급사 문서·계약 확인, 테스트 채널 수신, 원본 대조, 전환 계획 (docs/INTEGRATION.md).
2. 실제 공급사 어댑터·백필·첨부파일 저장/열람.
3. 실제 Claude API 키로 AI 직원·상담 분석·초안·보고서 해석 동작 확인 및 프롬프트 조정.
4. Web Push(VAPID) — 현재는 앱 안 알림함만.
5. 실시간 동기화(SSE/WebSocket) — 현재 주기적 재조회.
6. 보관 정리 대상에 AI 대화 기록·보고서 본문 포함.
7. 실기기(iOS Safari/Android Chrome) PWA 설치·한 손 사용성 점검.
8. 3단계 항목(앱 내 답장, 견적 문서, 일정·납품, 캠페인 분석, 인건비 세분화 등).
9. 로그인 시도 제한이 프로세스 메모리 기반 — API를 여러 인스턴스로 늘리면 공유 저장소로 옮겨야 함.
